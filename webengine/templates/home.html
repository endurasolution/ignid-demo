Ignid Webengine

This site runs on a native executable written entirely in Ignid: the HTTP parser, the template engine, the static file server and the hardening are all Ignid code, running on raw Winsock.

  • /hello?name=Ignid: a template with an escaped variable
  • /users: a list built from a partial template
  • /guestbook: a form, POST, and a template if/else
  • /users/42: path parameter, JSON
  • /api/status: JSON status
  • /crash: a handler that throws, so you get a 500 while the server stays up
  • /broken-template: a template error (start with --debug to see details)
