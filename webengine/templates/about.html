About

Pages are HTML templates in templates/: {{ value }} is escaped, {{{ value }}} is raw, and {% include %} and {% if %} work the way you'd expect.

Files in public/ are served as they are, any type (images, fonts, PDF, video), streamed straight from disk.

Every response carries a strict Content-Security-Policy, nosniff and frame-deny headers. The process recycles itself before its memory can run out.
